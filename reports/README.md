# Local results and evidence

Generated inference, claim, PDF and evaluation runs stay here locally and are
excluded from new Git delivery. Existing tracked outputs require the manual
index-only cleanup in [docs/CLEANUP_REPORT.md](../docs/CLEANUP_REPORT.md); nothing
was deleted locally. Historical phase-preparation documents remain tracked.

Use unique run/request directories. Keep genuine raw outputs and measured
denominators for local audit; never substitute labels for model predictions.
Published result summaries and limitations are in the root README. A private
report is not safe to publish merely because it was generated by this prototype.
